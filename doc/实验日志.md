# 2021.10.19

## 毕业设计研究点一: GRU 实验
### 上月回顾
- 上个月（2021年9月）针对 2021 年 1 月 5 日至 20 日捕获的 7 个总共大小为 155 GB 的 PCAP 文件，使用 tshark + Lua 完成了相关特征提取，并进行相关实验：
  - 把原始流量转化为 tcp json 格式的文本文件、把 tcp json 格式的文本文件转化为 TLS 客户端对应的报文序列
  - 基于源IP的 GroupBy 和 Combination、构造正负（NAT/非NAT）样本的 TLS 客户端保温序列，共获得样本 12 万个左右
  - 使用 Pytorch 搭建 GRU 网络进行简单的正负样本分类

### 本月完成
- 本月（2021年10月），在上月的基础上，完成以下工作：
  - 通过下采样，解决了正负样本不平衡的问题（原本正样本只有负样本的 1/20）
  - 选择不同参数（TLS 客户端报文序列的长度、采样的比例、batchsize 大小）训练不同的 GRU 模型，以获得最佳的 f1 值的表现，共训练了 1575 个不同的 GRU 模型。结果表明在 TLS 报文序列长度为 25-100，采样比 1-3，batchsize 大小为 32-128 时，能获得 90% 以上的 f1 值

## 调研学习
- 调研 TLS 1.3，阅读 rfc-8446（TLS 1.3）、rfc-5246（TLS 1.2）及相关中文博客，了解到一个 TLS 1.3 会话的 PSK 可以同时存在多个、而 TLS 1.2 会话的 Session Ticket 只能同时存在一个。因此，无法对 TLS 1.3 客户端报文序列应用研究点二的 GRU 模型
- 思考毕业设计研究点一的实验方案，读论文《How Many Users Behind A Local Recursive DNS Server? Estimated by Delta.Time Cluster Model》、《Accurate DNS query characteristics estimation via active probing》
